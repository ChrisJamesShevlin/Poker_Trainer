POKER STUDY TOOL (play money only)
==================================

To start:   double-click  PokerStudy.exe
            A black window opens and the game appears in your web browser.
            Keep the black window open while you play. Close it to quit.

First time only: Windows may say "Windows protected your PC" because this program
is not signed by a big publisher. Click  More info,  then  Run anyway.

Your game is saved on YOUR computer only, in:
    %APPDATA%\PokerStudyTool
(paste that into the Windows Explorer address bar to open it). Nothing is sent anywhere.
To start again from scratch, close the game and delete that folder.

To update: unzip the new version over the old one. Your save is kept, because it is not
stored with the program.

This is a study tool for learning poker against computer players. It is not a way to win money.
